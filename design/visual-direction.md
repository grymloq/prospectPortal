# Visual direction

Generated using the built-in image-generation tool, then implemented as code-native React UI. The concept is a design reference, not a screenshot of a working app. The live application uses real computed values from explicitly fictional seed records; incorrect generated dates/scores in the concept are not copied.

Tokens: navy `#102a43`, page `#f7f9fc`, white surfaces, ink `#102039`, muted `#687b90`, borders `#e6ebf1`, yellow `#f5cf43`, blue `#387dce`, green `#278549`. Inter/Arial typography, 36px headings, 12–14px UI text, 8px panel radius, thin borders, restrained shadows. Side navigation becomes a horizontal scrolling bar on phones. Tables scroll within their own containers.

Component families: sidebar navigation, metrics, filtered roster table, profile tabs, native modal forms, score rows, message streams, goal forms, calendar/agenda, and phase columns. No generated image is used as a substitute for working controls.

Generation prompt:

> Use case ui-mockup. Create one high fidelity desktop web application screenshot for Swedish national Warhammer 40k team selection tool called TEAM SWEDEN / 40K NATIONAL TEAM. 1536x1024 landscape. Crisp practical React UI, white background #f7f8fa, deep navy #102a43 vertical sidebar 224px, yellow #f3cf47 active highlights. Airy professional editorial sports operations dashboard. Sidebar small Swedish flag, TEAM SWEDEN, navigation Overview, Prospects (selected), Game journal, Calendar, Selection, Settings; bottom local demo admin account. Main primary screen heading 'Prospects' with sentence 'Build the next eight.' right yellow 'Review applications' button. Four flat compact metrics 12 Active prospects, 4 Awaiting review, 3 / 8 Selected, 28 Games this month. Below thin tab bar All prospects / Application / Phase 1 / Phase 2 / Selected then search field and faction filter. Main beautiful readable table with columns Player, Army, Phase, Games, Avg. score, Focus goals and rows fictional names Alex Berg (Orks), Robin Lind (Aeldari), Sam Nyström (Space Marines), Kim Dahl (Tyranids), Charlie Ek (Necrons), Dani Holm (Astra Militarum). Initial circles not photographs, subtle status chips, slim horizontal goal progress. Right narrow open rail 'Next team event' with September 19 training day, Stockholm, 8 player places, and 'Selection progress' small horizontal bars. No hero art, no illustrative dashboard filler, no badges above heading. Include complete screen footer breathing room. All controls and text implemented as code later. Refined 14px table typography, large 32px heading, 8px corner radii. This screenshot is visual concept only, fictional data.
